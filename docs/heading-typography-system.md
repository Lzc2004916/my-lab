# Card Theme Heading Typography — Design System Documentation

> Generated: 2026-07-13

## Overview

This document catalogs per-theme heading typography configurations. Each theme can independently specify H1-H6 font sizes, line heights, margins, weights, and colors. Themes without explicit config fall back to `HEADING_SIZE_RATIOS`.

## Extending the System

To add heading config to a new theme, add a `heading` block inside `editor`:

```typescript
editor: {
  bodySize: 30,
  lineHeight: 1.84,
  highlightStyle: "underline",
  heading: {
    h1Scale: 3.5, h2Scale: 1.7, h3Scale: 1.35,
    h1LineHeight: 1.25, h2LineHeight: 1.35,
    h1FontWeight: 700,
    h1MarginTop: 24, h1MarginBottom: 12,
    h1Color: "#c8a44e",
  },
},
coverHeading: {
  h1Scale: 4.8, h1LineHeight: 1.15, centered: true,
},
```
